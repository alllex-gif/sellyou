# Controllers Directory

This folder will contain business logic for handling requests:

- `authController.js` - Handle user signup, login, logout
- `freelancerController.js` - Handle freelancer profile operations
- `businessController.js` - Handle business owner operations
- `serviceController.js` - Handle service search and filtering
- `messageController.js` - Handle messaging
- `projectController.js` - Handle project operations

Controllers process requests and send responses.
