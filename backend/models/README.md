# Models Directory

This folder will contain database models and schemas:

- `User.js` - User model (base for all users)
- `Freelancer.js` - Freelancer profile model
- `Business.js` - Business owner model
- `Service.js` - Service/skill model
- `Project.js` - Project model
- `Message.js` - Message model
- `Review.js` - Review/rating model

Models define how data is structured in the database.
