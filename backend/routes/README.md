# Routes Directory

This folder will contain all the API routes for SellYou:

- `auth.js` - User authentication (login, signup, logout)
- `freelancers.js` - Freelancer profile endpoints
- `businesses.js` - Business owner endpoints
- `services.js` - Service search and listing
- `messages.js` - Messaging between users
- `projects.js` - Project posting and management

Each route file will handle requests for its specific feature.
